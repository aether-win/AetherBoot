m/Ctrl+m - Suma de comprobación de la imagen (md5/sha1/sha256/sha512)
d/Ctrl+d - Modo Memdisk (solo para ISO/IMG pequeñas de WinPE/LiveCD)
w/Ctrl+w - Modo WIMBOOT (solo para ISO de Windows/WinPE)
r/Ctrl+r - Modo GRUB2 (solo para algunas distribuciones Linux)
i/Ctrl+i - Modo compatible (solo para depuración)
u/Ctrl+u - Cargar controlador ISO EFI (solo para depuración)
