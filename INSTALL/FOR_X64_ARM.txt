============ Aether2Disk para x86_64 / ARM / ARM64 ============
Aether2Disk.exe es una aplicación de 32 bits (x86) que funciona en Windows de 32 y 64 bits
con procesadores Intel/AMD. Es la que conviene usar en casi todos los casos.

En la carpeta "altexe" del paquete hay versiones específicas:
  Aether2Disk_X64.exe    (Windows de 64 bits, Intel/AMD)
  Aether2Disk_ARM64.exe  (Windows en ARM de 64 bits)
  Aether2Disk_ARM.exe    (Windows en ARM de 32 bits)

Para usarlas, cópielas a la carpeta superior (junto a Aether2Disk.exe).
